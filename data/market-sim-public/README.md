# 공개 자료로 다시 구성한 가명 판매자 (t43 미리미리 · t44 정렬주의자 · t45 엠빅딜)

전략 마켓에 올리는 데모 판매자 3명의 원자료. 이름은 별명이고, 실제 투자자나 회사가 운영하거나 보증하는 계정이 아님 (판매자 소개 마지막 줄에 같은 안내).

## 파일
- `sellers/tNN.json` — 공시 · 보도로 다시 모은 매매 · 노트 · 추정 시작 보유분. 백엔드 `scripts/public-sellers/data/tNN.json` 과 같은 파일 (운영 DB 데모 계정 demo-t43~45 에 들어간 것과 같음)
- `closes/{종목}.json` — 저장소 일봉(market-data/daily) 종가 `[날짜, 종가]`, 2026-11-12까지 (평가금 · 월 수익률 · 보유 중 평가에만 씀)

## 만들기
```bash
python3 scripts/market-sim/public_build.py   # app/marketplace/sim.json 의 t43~t45 + data/market-sim/t43~t45.json (다른 트레이더는 그대로)
```

## 다른 데모 판매자와 다른 점
- 달 기록에 일봉을 넣지 않음 (`candles: []`) — 전략 상세 · 연습하기 · AI 답 차트가 열 때 일봉 API(`/charts/{종목}/bars`)로 받음
- 안 판 물량은 '보유 중' 매매 (`open: true`, exit = 마지막 종가로 평가). 화면은 매도로 그리지 않음
- 계획 가격이 없던 매매는 `followed: null` → 이행률에서 빼고 '—', 거래 내역에는 '계획 없음'
- 기준일(asOf)이 2026-11-12 (저장소 일봉 마지막 날). 종가를 새로 받으면 `closes/` 를 바꾸고 다시 만들면 됨
- 새 메모를 더하면 `sellers/` 를 백엔드와 같게 바꾸고 다시 만듦 (판매 최소 조건: 최근 30일 메모 5개)
