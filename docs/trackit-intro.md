# TRACKIT 소개 페이지

- 경로: `/intro`
- 개발 실행: `npm run dev` → `http://localhost:3001/intro`
- 포트가 사용 중이면: `npm run dev -- --port 3002`
- 검증: `npm run typecheck`, `npm run build`
- 현재 Windows 환경의 Turbopack 하위 프로세스 오류를 피하기 위해 개발·빌드 모두 Webpack을 사용합니다.

## 구성

1. 네 가지 문구가 교체되는 히어로. 9초 자동 루프: 정렬 → 줄마다 다르게 흩어진 한 칸 크기의 빈 공간 확장 → 가로·세로가 동시에 움직이는 네 박자 → 좌우 압축·정렬. 빈 칸 배치는 반복마다 달라지며, 확장 직후 열 전체가 비는 배열은 사용하지 않습니다. 각 박자에서는 이동 경로 전체를 예약해 다른 도형의 경로와 교차하지 않도록 합니다. 네 번째 박자에는 한쪽 바깥 줄에서 왼쪽 끝 퇴장·오른쪽 끝 진입을 진행하고 다른 두 줄에서는 세로 이동을 함께 진행합니다. 모든 도형은 세 줄 높이 안에서 한 축으로만 이동하며 중앙 로고 자리는 정렬 상태에서 비웁니다. 화면 밖·비활성 탭에서는 멈추고 모션 감소 설정에서는 정적 정렬 상태를 보여줍니다.
2. 검정 TRACKIT 박스 주위를 여섯 기능명이 회전합니다.
3. 예시 캔들 차트에 선과 설명이 나타나고 카드 여섯 장이 쌓입니다.
4. 카드가 남색 네모로 축소되어 아래 기능 그리드로 이어집니다.
5. 여섯 기능 카드와 시작 CTA·도형 시계로 마무리합니다.

`Intro.tsx`의 `tones`, `words`, `labels`가 색상과 문구를 관리합니다. `intro.css`는 `.ti` 접두어로 기존 화면과 스타일을 구분합니다. 모바일 및 모션 감소 설정에서는 카드를 일반 세로 목록으로 보여줍니다.

차트와 AI 기록은 프런트엔드 데모입니다. 실제 AI 호출이나 주문 실행은 포함하지 않습니다. 시작 CTA는 기존 `/workshop`, 전략 카드는 `/marketplace`, 로그인은 `/login`으로 연결됩니다.

## 도형 동작 검증

`node docs/verify-hero-motion.cjs`는 20회 반복의 18,001개 시점을 검사합니다. 흩어진 한 칸 크기의 빈 공간, 각 박자의 가로·세로 동시 이동, 도형별 단일 축 이동, 모든 도형 쌍의 이동 중 겹침, 세 줄 경계 이탈, 양 끝 출입 규칙, 반복 경계의 위치·정체성 연속성을 검사합니다. 타임라인과 팔레트는 `app/intro/hero-motion.ts`에서 관리합니다.
