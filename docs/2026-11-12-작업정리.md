## 1. 프론트엔드 — 작업실 (`/workshop`)

### 화면
- 공통 헤더(`SiteHeader`)로 홈·로그인·작업실 로고·메뉴 위치 통일
- 구성: 차트 + 오른쪽 AI 노트(매매하기를 누르면 매매 창) + 아래 기록
- 차트 높이 고정(보조 지표 2개까지 화면 안에 들어오게), 전체화면은 두 버튼 모두 같은 오버레이

### 차트
- **시세**
  - 키움 시세, 1985년~ 일봉 전체, 1분·1시간봉, 실시간 체결·초봉
  - 정규장(09:00~15:30)만 반영
  - 양봉 초록 / 음봉 빨강
- **봉 간격**
  - 1초 · 1분 · 1시간 · 1일 · 1주 · 1년
  - 직접 설정(초·분·시간·일·주·년)
  - 지표 버튼 앞에 둠
- **지표** (약 38종)
  - 기본은 거래량만
  - 고르기 창: 검색·즐겨찾기·차트 위/아래 분류
  - 이동평균은 5·20·60·120 네 선을 지표 1개로 묶음
  - signal 선 기본 9, 색 프리셋
  - 수급 지표: 투자자 순매수, 외국인 보유율, 공매도, 체결강도, CVD
  - 보조 지표는 창에서 2개까지, 전체화면에서는 더 많이 보임. 칸별 범례, 회색 구분선
- **드로잉** (73종, 트레이딩뷰식 분류)
  - 도구 목록: 모양 아이콘 + 이름 + ⓘ 설명, 밖을 누르면 닫힘
  - 선택·이동·점 수정·색·굵기·복제·삭제 툴바. 도구를 고른 상태에서도 기존 드로잉 선택 가능
  - 휴지통: 선택 삭제 / 모두 삭제
  - 그리면 자동 저장
- **시나리오** (캔들 버튼): 가장 최근 드로잉 기준 미래 5영업일 반투명 캔들 3묶음
  - 선 → 반등 / 이탈 / 횡보
  - 채널·박스 → 상단 돌파 / 하단 이탈 / 횡보
  - 롱·숏 포지션 → 목표가 / 손절가 / 진입가 횡보
  - 피보나치 → 윗선 반등 / 아랫선 하락 / 구간 횡보
  - 마우스 올리면 진하게, 클릭하면 하나만 남김, "다시 고르기"
  - "예시 경로이며 예측이 아닙니다" 표시. 1일봉 전용
- **저장 버튼** (차트 박스 오른쪽 끝)
  - 드로잉·노트를 일지에 저장
  - 백엔드 AI 차트 메모 결과를 오른쪽 "차트 메모"·"자동완성 제안"에 넣음
  - 확정은 사용자가 "확인하고 저장"을 눌러야 됨
- **그 밖**
  - 장 단계 표시(프리마켓·장 열림·애프터마켓·장 마감·휴장)
  - 평균 단가 점선
  - 날짜 축 뉴스 버튼
  - 검색창은 누르면 비워지고, 밖을 누르면 원래 종목으로 돌아옴

### AI 노트 · 기록
- AI 노트: 메모 + 자동완성 제안 + 체결 연결 추천
  - 사전 기록은 자동 연결, 사후 기록은 확인 필요
- 메모 칸이 아래로 늘어나고 "확인하고 저장"은 아래에 맞춤
- 기록
  - 기간 조회(오늘 / 1주일 / 1개월 / 직접입력), 날짜별 카드
  - + 로 작성: 종목을 검색해 쓰거나, 종목 없이 시장·뉴스·거시 생각을 씀

### 매매 창
- 탭: 직접 주문 / 알고리즘(백엔드 `/algo` 규칙 — RSI·SMA 교차·조건 조합, 로그인 필요)
- 호가
  - 키움 실시간 10단계, 3열(매도 | 가격 | 매수)
  - 현재가 한 줄만 굵은 테두리
  - 장 밖에는 "마지막 호가" 표시
- 주문 (OKX 참고)
  - 가능 수량, 0~100% 슬라이더(눈금에 붙음), 고정 주문 버튼
  - 수수료·매도세 반영: 매수 가능 수량은 수수료 포함, 총 결제·받을 금액 표시
- 제목·폭을 AI 노트와 맞춤. 탭을 바꿔도 폭 그대로
- 주문은 모의(로컬)

### 기업 정보 (매매 중 아래)

## 2. 백엔드 — API (`/api/v1`, 로그인 없이 조회)

| API | 내용 |
|---|---|
| `GET /charts/symbols` | 종목 검색 |
| `GET /charts/{code}/bars` | 봉 (일봉 1985년~ 전체, 분·시간봉 캐시) |
| `GET /charts/{code}/stream` | 실시간 체결 SSE (키움 0B) |
| `GET /charts/{code}/orderbook`, `/orderbook/stream` | 호가 10단계 + 실시간 호가 SSE (키움 0D) |
| `GET /charts/{code}/company` | 기업 정보 (ka10001, 하루 캐시) |
| `GET /charts/{code}/flows` | 수급: 투자자·공매도·외국인 보유율·체결강도 |
| `GET /charts/{code}/costs` | 수수료율(모의 0.35% / 실거래 0.015%)·매도세율(0.20%) |
| `POST /ai/chart-memo` | 드로잉·노트 → 판단 메모 초안 (규칙 기반 `rule-v1`) |

- 정규장 기준
  - 실시간 체결·분봉은 09:00~15:30 것만 씀
  - 최근 일봉은 정규장 1분봉으로 다시 계산
- 키움 실시간 연결 하나로 체결·호가를 같이 받음
- `docs/frontend-api.md`, `.env.example` 갱신

## 4. 지킨 원칙

- 프론트는 AI(Gemini·OpenAI·MCP)·증권사 API 를 직접 부르지 않고, 백엔드 API 만 씀. 컴포넌트에서 fetch 직접 호출 안 함
- 브라우저에는 Supabase 공개 URL·anon key 만 둠. 비밀값은 출력·노출하지 않음 (KRX 비밀번호는 해시로만 비교)
- AI 결과는 초안일 뿐
  - 확정은 사용자가 "확인하고 저장"
  - 주문은 사용자가 최종 승인한 뒤에만
  - 실패해도 재주문 자동 실행 없음
- "AI" 기능은 모두 **규칙 기반**(LLM 호출·키 없음): 차트 메모, 시나리오, 체결 연결 추천

## 5. 아직 안 한 것 · 알아둘 것

- **아직 안 올린 것** (로컬만): 호가 현재가 테두리를 2px → 1.5px 로 조정. 다음 푸시 때 같이 올라감
- **LLM 연결 안 됨**
  - 차트 메모를 진짜 AI 로 바꾸려면 백엔드 `.env` 에 키를 넣고 `lib/ai/chart-memo.ts` 의 `chartMemo()` 안만 교체
  - 입력·출력 형식은 유지
- **노트 확정 저장과 시나리오 연결 안 됨**
  - 선택한 시나리오를 노트 확정(`note-versions`)에 넣는 부분은 아직 없음
  - `lib/api-client.ts` 의 `apiFetch` 는 `credentials: "include"` 때문에 백엔드 CORS(허용 헤더 없음)에서 막히고, 실패 시 서버 메시지도 버림
  - `lib/api/client.ts` 의 `apiRequest` 를 쓰면 문제 없음
- **기업 실적은 연간(12월 결산)만**: 분기 실적·TTM 은 DART OpenAPI(무료 키) 연결이 필요
- **KRX 계정 값**
  - `trackit_frontend/.env.local`, `trackit_backend/.env` 에 들어 있는 `KRX_ID`/`KRX_PW` 는 빼는 것을 권장 (`Trackkit_prac/.env` 에만 있으면 됨)
  - 로그인 반복 실패 시 계정이 잠길 수 있음
- **백엔드 개발 서버**: 오늘 마지막에 꺼진 상태(종료 코드 4)
  - 다시 켜기: `trackit_backend` 에서 `npm run dev` (포트 3000)
- **삭제한 것**
  - 별도 `/workspace` 페이지: 시나리오를 작업실 드로잉 도구로 옮기면서 지움
  - 계산 코드(`lib/workspace/`)는 남김
