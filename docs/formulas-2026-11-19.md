## 1. 등급 산정 공식

### 1-1. 평가 방식

- 매달 1일에 다시 평가한다.
- 평가 기간은 최근 min(활동개월, 24)개월이다.
- 수익률은 주간 단위로 계산한다.

### 1-2. 지표 정의

| 지표 | 식 |
|---|---|
| 초과수익 R (연율, %) | mean(r_t − r_시장,t) × 52 × 100 |
| 샤프 SR (연율) | mean(초과수익) ÷ std(초과수익) × √52 |
| PSR | Φ( SR_w·√(n−1) ÷ √(1 − γ₃·SR_w + (γ₄−1)/4·SR_w²) ) |
| MDD (%) | 평가 기간 중 계좌 평가금액의 최대 낙폭 |
| 이행률 A_adj | 아래 1-3 (후보 7) |
| **일관성 C [변경]** | 아래 4장 |
| 활동기간 T | 증권사 연동이 유지된 개월 수 |

PSR 기호: SR_w = 주간 샤프, n = 주 수, γ₃ · γ₄ = 주간 초과수익의 왜도와 첨도.

### 1-3. 이행률 보정 A_adj (후보 7)

```
n     = N_t + κ·N_n
A_adj = A_t − (A_t − 0.5)·5/(n + 5) − λ·max(0, A_t − A_n)·κ·N_n / n
```

| 기호 | 뜻 | 값 |
|---|---|---|
| N_t, A_t | 매매 건수, 매매 이행 점수 (매수금액 가중평균) | a_i = 0.4·진입 + 0.4·손절 + 0.2·청산 |
| N_n, A_n | 노트 이행 건수(한 달에 최대 1건), 노트 이행 점수 | a_n = 0.5·조건 준수 + 0.3·판단 유지 + 0.2·사후 점검 |
| κ | 노트 1건을 매매 몇 건으로 칠지 | 0.5 |
| λ | 노트를 매매보다 덜 지켰을 때 감점 강도 | 1 |

**[변경]** 매매 이행 점수 A_t는 매도마다 3장의 이행률(누적 전략의 지지 · 저항 달성 여부)로 계산한다. 매도 금액으로 가중평균한다.

## 2. 가격 산정 공식

### 2-1. 성적 점수 E **[변경: 비중]**

```
E = 0.25·φ(f_R) + 0.20·φ(f_SR) + 0.225·φ(f_A) + 0.075·φ(f_C) + 0.15·φ(f_DD) + 0.10·τ
```

| 항목 | 11/17 | **11/19** | 정규화 |
|---|---|---|---|
| 수익률 | 0.25 | 0.25 | f_R = R / 10 |
| 샤프 | 0.30 | **0.20** | f_SR = (SR − 0.3) / 0.9 |
| 이행률 | 0.20 | **0.225** | f_A = (A_adj − 0.5) / 0.32 |
| 일관성 | — | **0.075** | f_C = (C − 0.5) / 0.32 |
| 낙폭 | 0.15 | 0.15 | f_DD = (50 − MDD) / 25 |
| 활동 기간 | 0.10 | 0.10 | τ = ln(min(T,24)/3) / ln 4 |

- 샤프를 0.3에서 0.2로 줄였다. 그 결과 이행률 몫이 0.3이 되고, 이를 **이행률 : 일관성 = 3 : 1**로 나눴다.
- 각 지표는 D 기준선에서 0, A 기준선에서 1이 되도록 맞췄다.
- τ는 3개월이면 0, 12개월이면 1, 24개월이면 1.5이다.
- φ(x)는 구간마다 다르게 계산한다.
  - x ≤ 0이면 0
  - 0 < x ≤ 1이면 x^1.5. 기준선 근처에서는 점수가 천천히 오른다.
  - x > 1이면 1 + 1.5·ln x. A를 넘어서는 로그로 완만하게 오르고 상한은 없다.

### 2-2. 가격 P (등급 기준점을 잇는 복리 보간)

```
P = L_g × (L_{g+1} / L_g) ^ ((E − E_g) / (E_{g+1} − E_g))
```

| 등급 | 하한 L_g | 기준점 E_g |
|---|---|---|
| D | 4,000 | 0 |
| C | 7,000 | 0.172 |
| B | 20,000 | 0.463 |
| A | 120,000 | 1.0 |
| VIP | 500,000 | 1.439 |

- VIP 위로는 A→VIP 구간과 같은 기울기로 계속 오른다.
- 구간별 기울기는 3.25~3.6으로 거의 같아서, 사실상 공식 하나로 봐도 된다.

### 2-3. 가격 적용 규칙

- 첫 등급이 D이면 5,000원에서 시작한다. C · B는 공식가를 그 등급 범위 안으로 맞춘다.
- **[변경]** 승급하면 새 등급 하한가에서 다시 시작한다. (11/17: max(공식가, 새 등급 하한))
- **[변경]** 강등하면 아래 등급 상한가(다음 등급 하한 − 1단위)부터 시작한다. (11/17: 새 등급 범위 안에서 공식가)
- D, C, B는 범위 [등급 하한, 다음 등급 하한) 안에서만 움직인다.
  - 그 등급에 들어온 첫 달 가격의 −20%~+30% 안에 머문다.
  - 한 달 변동은 ±10%까지다.
- A와 VIP는 상한이 없고, 하락만 한 달 10%까지로 제한한다.

## 3. 이행률 (11/19 회의)

**매도 시점까지 누적된 전략(메모)의 달성 여부**이다.

### 3-1. 지지 · 저항 분류 (알고리즘)

사용자가 차트에 선만 그어도 알고리즘이 지지 · 저항을 정한다. 매매 계획을 따로 채울 필요는 없다.

| 선 종류 | 기준 | 지지 | 저항 | 나눌 수 없음 |
|---|---|---|---|---|
| 수평선 · 가격 표시 | 현재가 | 현재가보다 0.5% 넘게 아래 | 0.5% 넘게 위 | 현재가 ±0.5% 안 |
| 피보나치 (레벨마다 한 줄) | 현재가 | 〃 | 〃 | 〃 |
| 사각형 · 가격 범위 · 채널 (구간) | 현재가 | 구간 전체가 아래 | 구간 전체가 위 | 구간이 현재가를 걸침 |
| 추세선 · 반직선 (기울어진 선) | **차트 마지막 봉** | 그 봉 시각의 선 값이 봉 몸통 아래 | 몸통 위 | 몸통을 지남 |

- **[구현]** 추세선 값은 차트와 같은 **봉 순서**로 계산한다. 주말 · 휴장은 칸이 없으므로 달력 시간이 아니다. 두 점이 같은 시각인 선(길이 0)은 뺀다.
- 나눌 수 없는 선은 사용자가 지지 · 저항을 고른다. **고르지 않으면 이행률 계산에서 빠진다.**
- 선마다 매매를 더 고를 수 있다. 지지선은 매수 · 손절, 저항선은 목표 · 매도이다.
- 뉴스 · 경제 지표 메모의 정량 전략(종목 · 가격 · 매수/매도)도 같은 선으로 쌓인다. 매수는 지지, 매도는 저항이다.
  - 예) "삼성전자 210,000원에 매도"는 삼성전자 전략에 210,000원 저항선으로 쌓인다.

### 3-2. 판정

1. **누적 전략**: 매도 시점까지 쌓인 선을 모두 모으고, 수정된 전략은 수정본으로 바꿔 계산한다.
   - 수정 기준: 종목 · 거래 행동은 그대로 두고 지지/저항의 위치만 바꾼 것이다.
   - 예) 삼성전자를 21만원에 판다 → 22만원에 판다 (수정 O)
   - 회의 예시: A, B, C가 A', B', C'로 바뀌고 D, E는 유지되면, 매도 시점의 전략은 A', B', C', D, E이다.
   - 메모를 지우면 그 메모로 쌓인 선도 빠진다.
2. **대상 선**: 매도 시점 시장가에 가장 가까운 **지지선 5개 · 저항선 5개**만 센다. 과하게 작도해 이행률을 높이는 것을 막기 위해서다.
3. **선마다 이진 판정 (1 / 0)**: 보유 기간 동안 가격이 그 선을 지켰는지 본다. 보유 기간은 직전 매수부터 매도까지이고, 선을 그은 뒤부터 센다. 일봉 종가 기준이며 0.5% 여유를 둔다.
   - 지지선: 종가가 선 아래로 내려간 날이 없으면 1
   - 저항선: 종가가 선 위로 올라간 날이 없으면 1
4. **매도 한 번의 이행률** = 지킨 선 수 ÷ 판정한 선 수
5. **분석 순서**: 1차 알고리즘(위 판정)을 하고, 2차로 AI가 fallback 한다.
   - AI는 알고리즘으로 계산하기 어려운 전략(글로만 적은 조건, 매매를 고르지 않은 뉴스 메모)을 정성 분석해 넣을지와 일치 비율을 정한다.
   - 넣지 않으면 그 전략은 이행률 계산에 들어가지 않는다.

## 4. 일관성 지표 (11/19 회의)

**전략이 얼마나 일관되게 유지되느냐**를 잰다. 한 시점의 전략은 메모 하나에 담긴 선 묶음이다(차트 노트는 그때 차트의 선을 모두 담는다). 위치만 고친 선은 유지로 본다.

유지율(이번, 직전) = |이번 전략 ∩ 직전 전략| ÷ |이번 전략|

- **월 안**: 그 달에 바꾼 횟수만큼 메모끼리 유지율을 내고 평균한다.
  - 예) A → A,B → A,B,D → B,C 이면 50% · 66% · 50%
- **월 사이**: 그 달의 전략(달 마지막 메모) 가운데 직전 달 전략에서 이어진 비율이다.
  - 예) 1월 A,B → 2월 B,C 이면 B만 이어지므로 **50%**
- 일관성 C = 월 사이 유지율의 평균 (평가 기간 안, 2개월 이상일 때. 그 전에는 0.5)

> 회의록 표의 세 번째 값(A,B,D → B,C = 33%)은 위 식으로 계산하면 50%(B 1개 ÷ 이번 전략 2개)이다. 33%는 직전 전략 3개로 나눈 값이라 확인이 필요하다.

## 5. 수수료 (D 20%, VIP 1%)

20%에서 1%까지 4단계를 같은 비율(약 0.47배씩)로 내리고, 딱 떨어지는 숫자로 반올림했다.

| 등급 | 수수료 | 하한가 기준 판매자 수령액 |
|---|---|---|
| D | 20% | 4,000 → 3,200 |
| C | 10% | 7,000 → 6,300 |
| B | 5% | 20,000 → 19,000 |
| A | 2% | 120,000 → 117,600 |
| VIP | 1% | 500,000 → 495,000 |

- 등급이 하나 오를 때마다 수수료가 대략 절반이 된다.
- 플랫폼 수익은 거의 D와 C 판매에서 나온다(등급 판매자의 약 88%가 D와 C로 예측됨). A와 VIP는 신뢰를 보여 주는 간판 역할이다.

## 6. 비즈니스 계정 전환 기준 (11/17, 그대로)
