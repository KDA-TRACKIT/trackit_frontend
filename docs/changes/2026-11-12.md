## 3. AI 노트 · 기록

- AI 노트: 메모 + 자동완성 제안, 체결 연결 추천
  - 사전 기록은 자동 연결, 사후 기록은 확인 필요
- "확인하고 저장"은 메모 칸 아래에 맞춤
- 기록
  - 기간 조회(오늘 / 1주일 / 1개월 / 직접입력), 날짜별 카드
  - + 로 작성: 종목을 검색해 그 종목에 대해 쓰거나, 종목 없이 시장·뉴스·거시 생각을 쓸 수 있음

## 4. 매매 창

- 탭: 직접 주문 / 알고리즘(백엔드 `/algo` 규칙: RSI·SMA 교차·조건 조합)
- 호가: 키움 실시간 10단계(매도 | 가격 | 매수 3열)
  - 굵은 테두리는 현재가 한 줄만(1.5px), 매도·매수 경계는 얇은 선
  - 정규장이 아니면 "장 마감 · 마지막 호가" 표시
- 주문 (OKX 참고)
  - 매수·매도 가능 수량 표시, 0~100% 비율 슬라이더(눈금에 붙음)
  - 주문 버튼은 고정 위치(떠다니지 않음)
- 거래비용: 백엔드 요율(`/charts/{code}/costs`)로 수수료·매도세 계산
  - 매수 가능 수량은 수수료까지 포함
  - 총 결제 금액·받을 금액 표시
- 매매 창 제목은 AI 노트 제목과 같은 크기·위치. 직접 주문↔알고리즘을 바꿔도 폭이 그대로
- 주문은 모의 주문(로컬). 실제 주문 API 는 호출하지 않음
