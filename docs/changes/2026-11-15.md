### 증권사가 연결돼 있는데 "계좌 연결하기"가 뜨던 것
- 원인
  - 증권사 체결은 **동기화**를 해야 매매 기록(Trade)·포지션·성과에 들어감
  - 동기화는 하루 1회 크론이나 작업자 엔드포인트에서만 돌고, 프론트는 동기화를 부르지 않았음
  - 실제 계정 상태 (읽기만 해서 확인)
    - 키움 모의 1계좌 연결(ACTIVE)
    - 잔고 스냅샷엔 3종목 보유 (000660 100주, 005930 1,001주, 034020 20주)
    - 동기화는 **11.12 14:00까지**만 돼 있고 매매 기록은 0건
- 고친 것
  - 홈이 연결된 계좌와 동기화 상태(`GET /brokers/accounts/{id}/sync`)를 같이 읽음
  - 연결돼 있고 체결이 없으면: "증권사 체결이 아직 반영되지 않았어요 · 키움 모의 · 11.12 14:00까지 반영" + **지금 불러오기**
  - 체결이 있으면 표 아래에 "… 까지 반영 · 새로 불러오기"
  - 버튼은 계좌마다 `POST /brokers/accounts/{id}/sync { now: true }`(바로 처리) 후 홈 숫자를 다시 읽음
  - 서버가 시간 안에 다 못 받으면 "일부만 받았어요" 안내 → 한 번 더 누르면 이어 받음
  - 연결이 없을 때만 "증권사 계좌 연결하기"
  - API: `lib/api/orders.ts` 의 `getSyncStatus`, `syncNow`
- 아직: 버튼은 누르지 않음
  - 동기화는 계정 기록을 쓰는 작업이라 사용자가 직접 누르도록 둠
  - 모의 계좌에서 체결 조회가 실제로 기록을 만드는지는 누른 뒤에 확인 필요

### 그리기 방식 스위치 · 도구 줄 (사용자 요청으로 다시 정리)
- 위의 "클릭이 안 먹던 것" 변경과 브러시 직선 보정을 **스위치로 분리**
  - 기본 동작은 원래대로 되돌림
  - 위치: 차트 위쪽 "✎ 차트 노트 ▾" 옆 **스마트 ON/OFF** (기본 OFF, 이 브라우저에 저장)
  - OFF: 원래 코드 그대로
    - 클릭으로 점 찍기 (5px 넘게 움직이면 무시)
    - 점 찍기 전엔 기존 드로잉을 눌러 고름
    - 브러시는 손그림
  - ON
    - 누름·놓음으로 점 찍기 (10px까지 흔들려도 클릭)
    - 끌어서 선 긋기
    - 도구를 든 동안 기존 드로잉 안 고름
    - 브러시·형광펜의 곧은 획은 직선으로
  - 브러시 메뉴의 "곧은 획은 직선으로" 체크는 없앰 (스위치로 옮김)
- 도구 줄 묶음 버튼이 **마지막에 쓴 도구를 기억**
  - 예: 라인 묶음에서 수평선을 썼으면, 다음엔 묶음 버튼 한 번으로 바로 수평선
  - 버튼 오른쪽 › 로 메뉴를 열어 다른 도구 선택
  - 메모리에만 둬서 새로고침·재접속하면 처음처럼
- 묶음 버튼에 **지금(마지막) 도구 아이콘**과 이름(마우스 올리면)이 보임
- 시나리오 안내 문구 줄임: "기준이 될 선·박스·포지션을 먼저 그려 주세요"
- 확인 (저장 요청을 막은 별도 탭)
  - OFF 깨끗한 클릭 → 선 ✓
  - OFF 7px 흔들린 클릭 → 원래처럼 무시 ✓
  - ON 같은 클릭 → 선 ✓
  - 수평선 쓴 뒤 묶음 버튼 한 번 → 수평선 ✓

### 화면 사이 통일 점검 (`app/consistency.css`)
- 모든 화면의 제목 크기·위치, 글꼴, 본문 글자 크기를 같은 방식으로 재서 비교
- 고친 것
  - **글꼴**: 홈·로그인·아이디/비밀번호 찾기만 Arial 이었음 → 전부 Pretendard (입력칸 포함)
  - **로그인·회원가입 흐름 제목**: 크기 20·30·38px, 시작 높이 67·120·200px 로 화면마다 달랐음
    - 지금은 모두 30px, 상단 바 아래 96px
    - 로그인 TRACKIT 은 로고라 38px 유지
  - **너무 작은 글자** (9~11px) → 12~14px
    - 로그인 아래 링크, "또는", Google 버튼, "이미 계정이 있으신가요", 회원가입 입력칸
- 그대로 둔 것

- 오른쪽 금리 눈금(범위에 맞춰 0.25·0.5·1%p) · 옅은 가로선 · 해마다 연도와 점선
- 바뀐 달에 점(인상 빨강 · 인하 파랑)과 폭(+0.25), 겹치면 최근 것만 글자 · 마지막 값 점 · 아래 옅은 채움
- 마우스를 올리면 세로선과 그 달 값 (미국은 목표 범위, 바뀐 달은 인상/인하 폭)
