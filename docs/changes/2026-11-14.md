## 랜딩 · 회원가입 (`Trackit (3).zip`)
- `/`
  - 로그인 전이면 랜딩(`app/Landing.tsx`, `app/landing.css`): 어두운 첫 화면, 3단계 설명, 시작하기 → `/signup`
  - 로그인했으면 기존 홈(`app/HomeDashboard.tsx`로 옮김)
- `/signup`: 일반 회원가입 / Google 계정으로 가입 고르는 화면
- `/signup/email`: 일반 회원가입 (기존 가입 폼을 여기로 옮김)
  - 입력 칸: 아이디(이메일), 비밀번호와 확인(눈 아이콘으로 보기/숨기기), 이름, 성별, 생년월일, 닉네임
  - 백엔드 `/auth/signup` 에는 지금처럼 이메일·비밀번호·닉네임만 보냄
  - 이름·성별·생년월일은 `user_metadata` 에 저장
  - 가입 확인 메일 때문에 바로 세션이 없으면, 이 브라우저에 잠시 두었다가 첫 로그인 때 넣음 (`app/auth-ui.tsx`)
- `/signup/complete`: Google 가입 마무리
  - 닉네임, 생년월일, 성별, 필수 약관 2개를 받음
  - `/auth/callback` 에서 **10분 안에 만들어진 Google 계정이고 아직 마무리 안 한 경우에만** 이리로 보냄 (예전 계정은 그대로 홈)
- `/onboarding`: 최초 프로필 생성
  - 마이페이지 투자 정보와 같은 입력 칸·같은 저장값
  - 나중에 설정하기 → 홈
- `/login`: Google 로고를 실제 색 로고로 바꿈. 첫 로그인 때 보관해 둔 가입 정보를 넣음

  - 누르면 지금처럼 마이페이지 · 로그아웃 메뉴
- 알림 종
  - 알림 API 가 없어 "새 알림이 없어요"만 보여 줌
  - 종을 누르면 계정 메뉴는 닫힘
- 로고·메뉴 위치와 글자 크기는 그대로 (한때 시안대로 줄였다가 되돌림 → 2026-11-15 기록)

## 그대로 둔 것 / 확인 필요
- 백엔드 `User` 테이블
  - `email`, `nickname` 만 있음
  - 마이페이지에서 닉네임을 바꿔도 `user_metadata` 만 바뀌고 DB `User.nickname` 은 그대로
  - 이름·성별·생년월일·소개·투자 정보도 DB에는 없음 (A 영역)
- 프로필 사진
  - 저장소(Storage) API 가 없어 이 브라우저에만 저장됨
  - `user_metadata` 는 로그인 토큰에 실려서 이미지를 넣지 않음
- 비즈니스 전환·판매·정산 화면은 판매자/열람권 API(다른 세션에서 설계 중)가 생기면 연결
