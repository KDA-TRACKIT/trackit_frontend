# 2026-11-18 변경 기록 (프론트)

## 로그인 · 회원가입 (시안 반영)
- 아이디를 이메일과 따로 둠: 가입 때 아이디 쓸 수 있는지 바로 확인, 로그인은 아이디 또는 이메일
- 회원가입 칸 순서 시안대로, 생년월일 달력(연·월 고르기), 약관 모달("동의하고 닫기" = 체크)
- Google 가입 마무리 화면도 같은 줄 배치 · 달력 · 약관
- 아이디 · 비밀번호 찾기를 로그인 화면 모달로 (`/find-id`, `/reset-password` 는 모달로 이동)
- 로그인 칸 글자가 누르면 위로 올라가는 라벨
- 가입 직후 "나만의 투자 정보 설정" 문구·버튼 시안대로
- 새 파일 `app/auth-forms.tsx`

## 트레이딩 로그 (차트)
- AI 노트 패널 단순하게 (풀이는 접어 두기, 저장 버튼 하나), 백엔드 새 칸(차트 구조 · 겹치는 근거 · 시나리오 · 확신도) 표시
- 노트 체크리스트 화면 다시 (매매 · 보유 · 관찰, 진행 막대, 빠진 항목 바로 넣기)
- 그날 종목·섹터 뉴스: 최근 뉴스 날짜에 원 하나, 날짜 축에 대면 원, 바깥 누르면 닫힘, 꿀벌 표시
- 드로잉: 도구를 든 채 기존 드로잉 선택(점 찍기 전까지), 한 번 클릭이 안 찍히던 것, 되돌리기로 첫 드로잉이 안 지워지던 것, 선택 시 설정 바
- 차트 처음 열 때 봉을 받기 전 실시간 체결이 붙어 초봉처럼 보이던 것

## For trade (투자 정보)
- 섹터맵: 처음부터 국내·미국 모두 받기, 시장 바꾸면 바로 새로 받기, 1분 넘은 값은 "갱신 중", 3초마다 갱신
- 시장 카드 시각 "MM.DD HH:MM" 로 통일

## 마이페이지
- 새 메뉴 구성(시안), 내 계좌 `/mypage/wallet`, 판매 · 설정 · 공개 범위 · 프로필 · 투자 정보
- 계좌 연결: 본인인증 → 계좌 찾기 → 전부 자동 연결 (시연은 서버 키움 키, 없으면 앱키 한 번 입력)
