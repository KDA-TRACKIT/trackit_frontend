## 작업실 차트가 "Cannot update oldest data" 로 멈추던 것 (`app/workshop/WorkshopChart.tsx`)
- 실시간 갱신은 "끝에 봉이 붙기만 했다"고 보고 update 를 불렀는데, 봉 목록이 밀리거나(가장 오래된 봉이 빠지고 새 봉) 다시 받아 시각이 달라지면 마지막보다 이른 시각이 들어가 lightweight-charts 가 멈춤
- 첫 봉과 직전 마지막 봉 시각이 그대로일 때만 update, 아니면 전체 교체. update 가 실패해도 캔들 · 지표 모두 전체 교체로
