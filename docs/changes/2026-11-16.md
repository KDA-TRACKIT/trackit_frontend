## 같은 와이파이의 다른 PC 에서 개발 서버 열기 (`lib/api-url.ts`, `next.config.ts`)
- `http://<내 IP>:3001` 로 열면 API 를 같은 주소(3001)로 부르고, 개발 서버가 `/api/v1/*` 를 백엔드로 넘김 (rewrites). 3001 하나만 열면 되고 CORS 필요 없음
- `allowedDevOrigins` 에 사설 IP 대역
- Google 로그인 시작할 때 지금 주소(`?origin=`)를 백엔드에 알려서 그 주소로 돌아옴. Supabase 는 Redirect URLs 에 IP 를 넣어도 받지 않아서 Site URL 을 그 IP 로 바꿔야 했음
